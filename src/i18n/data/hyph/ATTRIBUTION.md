# Hyphenation pattern attribution

The four `*.standard.bincode` files in this directory are Knuth–Liang
hyphenation dictionaries copied byte-for-byte out of the `hyphenation` crate
(version pinned in `Cargo.toml`; regenerated by
`scripts/make_hyphenation_data.sh`). The crate compiles them from the TeX
**hyph-utf8** pattern sets, whose authors and licences differ per language and
are reproduced here because this repository's own MIT licence (`LICENSE`) does
not cover them. Nothing in this directory is modified from the crate's copy.

| File | Language | Source pattern file | Copyright | Licence |
|---|---|---|---|---|
| `de-1996.standard.bincode` | German, reformed (2006) orthography | `hyph-de-1996.tex` (2024-02-28) | © 2013–2024 Stephan Hennig, Werner Lemberg, Günter Milde, Sander van Geloven, Georg Pfeiffer, Gisbert W. Selke, Tobias Wendorf, Keno Wehr (Deutschsprachige Trennmustermannschaft) | MIT |
| `en-us.standard.bincode` | English, American spelling | `hyph-en-us.tex` (2005-05-30) | © 1990, 2004, 2005 Gerard D.C. Kuiken | permissive notice (below) |
| `en-gb.standard.bincode` | English, British spelling | `hyph-en-gb.tex` | © 1992, 1996, 2005, 2016 Dominik Wujastyk, Graham Toal | MIT |
| `ru.standard.bincode` | Russian | `hyph-ru.tex` (2003/03/10) | © 1999–2003 Alexander I. Lebedev | LPPL 1.2 or later |

The master files, with these headers, are in the hyph-utf8 repository:
<https://github.com/hyphenation/tex-hyphen/tree/master/hyph-utf8/tex/generic/hyph-utf8/patterns/tex>.
